Cantoni

A simple, highscoring game built with Unreal Engine, utilizing point-and-click mechanics and a leaderboard system.

This game was created as an experimental project.

Project Overview

Cantoni is a lighthearted, casual point-and-click game built around a dynamic leaderboard system. The game was designed as both a fun interactive experience and a personal technical challenge to implement player data persistence and scoring mechanics within a complete gameplay loop.

Gameplay Concept

Players enter their name at the start of each session, which the game remembers for ranking on the leaderboard. The goal is to pop bubbles before they reach the three joyful characters in the center, scoring points and protecting happiness.

Leaderboard & Progression

Scores are saved and ranked in real-time. Only the top 10 players ("Top Poppers") are shown. Returning players can compare scores and replay for improvement.

Design & Aesthetics

Simple, clear visuals for quick-reaction gameplay. Expressive looping characters represent joy, with a spiky antagonist that shoots bubbles. Original soundtrack “Cantoni” sets the rhythm for gameplay. Clean UI for input, scores, and leaderboard display.

Development Details

Engine: Unreal Engine 5.5.4

Role: Solo developer — design, programming, sound, and visual direction.

Platform: PC (Windows)
